# Wohletz Roofing & Construction

Static site for wohletzroofingandconstruction.com. Edit build.py (pages) or public/styles.css (design), run `python3 build.py` to regenerate public/, then push. Cloudflare deploys automatically.

- Quote form posts through FormSubmit to info@wohletzroofingandconstruction.com, cc wohletztyler711@gmail.com. The first submission triggers a one-time FormSubmit activation email to info@.
- Old GoHighLevel URLs are redirected in public/_redirects.
